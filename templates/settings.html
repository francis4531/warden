One-time setup in Google Cloud
  1. Nothing to add under Credentials: connectors reuse the sign-in redirect URI, which is already registered. (If you bring your own client below, register {{ redirect_uri }} on it.)
  2. Enable the APIs you will use: Gmail, Drive, Calendar, Docs, Sheets.
  3. On the OAuth consent screen, add the scopes listed above.
  4. If your organization uses Google Workspace, set the app's user type to Internal: no verification is needed and every person in the organization can connect. Otherwise keep the app in Testing and add each person as a test user (up to 100) until the app is verified.
Bring your own Google client
Recommended for organizations on Google Workspace: create an OAuth client in your own Google Cloud project (user type Internal), and paste it here. It replaces the sign-in client for connectors only; sign-in is unchanged. Secrets are stored encrypted.
