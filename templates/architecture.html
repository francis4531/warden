Architecture

How Warden works.

An agent is instructions plus tools. The tools come from MCP servers you connect; every one is risk-classified on arrival; and every action the agent takes passes one gate before it happens. Here is the whole path.

agent & tool flow supporting wire executes on approval
The risk model
LOWReads, auto-run
Lookups, searches, file reads. No side effects, so the agent runs them on its own.
MEDReversible writes
Opening a ticket and the like. Runs automatically, but logged prominently.
HIGHIrreversible, gated
Moving money, writing files, creating PRs. Pauses for human approval before it runs.

Unrecognized tools default to HIGH. A tool from a server Warden has never seen is gated until a human decides otherwise, rather than trusted by default.

A run’s life
runningthe agent is reading and calling low/medium tools
awaiting approvala high-risk tool is held; a human must approve or deny
donethe agent finished; the full trace is in the audit log
